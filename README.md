# 🔔 Telegram Reminder Bot

Личный бот для напоминаний прямо в Telegram. Понимает русский язык, работает на VPS в Docker.

## ✨ Возможности

- 💬 **Естественный язык** — «через 1:20», «через час двадцать», «через 26 дней»
- 📅 **Даты и дни недели** — «завтра в 9:00», «в пятницу в 18:00», «в 25.12.2026»
- 🔁 **Повторяющиеся напоминания** — «каждый понедельник в 10:00»
- 💤 **Снуз-кнопки** — отложить на 30 мин / 1 час / 3 часа прямо в сообщении
- 🎙 **Голосовые сообщения** — надиктуй напоминание, бот распознает через Whisper
- 🔄 **Уведомление о перезапуске** — бот сам пишет после обновления, сколько напоминаний уцелело
- 📋 `/list` — список активных напоминаний
- ❌ `/cancel <id>` — отмена

## 📝 Примеры

```
напомни через 45 минут выключить духовку
напомни через 1:20 оплатить кредит
напомни через час двадцать позвонить маме
напомни через полтора часа про звонок
напомни через 26 дней про оплату форнекс

напомни завтра в 9:00 про отчёт
напомни в пятницу в 18:00 про встречу
напомни в 25.12.2026 в 10:00 про подарки

напомни каждый день в 9:00 про зарядку
напомни каждый понедельник в 10:00 про планёрку

напомни несколько раз через час и два часа про это
```

## 🚀 Установка одной командой

Нужен сервер с Ubuntu и установленным Docker.

```bash
curl -sSL https://raw.githubusercontent.com/wellbob/reminder-bot/main/setup.sh | bash
```

Скрипт сам:
1. Проверит наличие Docker
2. Спросит токен бота (получи у [@BotFather](https://t.me/BotFather))
3. Скачает файлы, соберёт образ и запустит бота
4. Выведет полезные команды для управления

## 📌 Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и примеры |
| `/list` | Список активных напоминаний |
| `/cancel <id>` | Отменить разовое напоминание |
| `/cancel r<id>` | Отменить повторяющееся |

## ⚙️ Управление после установки

```bash
cd /opt/reminder-bot

# Логи в реальном времени
docker compose logs -f reminder-bot

# Остановить
docker compose stop reminder-bot

# Перезапустить
docker compose restart reminder-bot

# Обновить до последней версии
git pull && docker compose build && docker compose up -d
```

| Планировщик | APScheduler 3.10 |
| Распознавание речи | OpenAI Whisper (tiny, локально) |
| База данных | SQLite |
| Деплой | Docker + Docker Compose |
