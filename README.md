# 🔔 Telegram Reminder Bot

Личный бот для напоминаний прямо в Telegram. Понимает русский язык, работает на VPS в Docker.

## ✨ Возможности

- 💬 **Естественный язык** — «напомни через 26 дней про оплату»
- 🔁 **Повторяющиеся напоминания** — «каждый понедельник в 10:00»
- 💤 **Снуз-кнопки** — отложить на 30 мин / 1 час / 3 часа прямо в сообщении
- 🎙 **Голосовые сообщения** — надиктуй напоминание, бот распознает через Whisper
- 📋 `/list` — список активных напоминаний
- ❌ `/cancel <id>` — отмена

## 📝 Примеры

```
напомни завтра в 9:00 про отчёт
напомни через 26 дней в 12:00 про оплату форнекс
напомни через час и полтора часа про звонок
напомни каждый день в 9:00 про зарядку
напомни каждый понедельник в 10:00 про планёрку
```

## 🚀 Быстрый старт

### 1. Создай бота

Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → сохрани токен.

### 2. Клонируй репозиторий

```bash
git clone https://github.com/ВАШ_НИК/reminder-bot.git
cd reminder-bot
```

### 3. Настрой окружение

```bash
cp .env.example .env
nano .env  # вставь свой BOT_TOKEN
```

### 4. Запусти

```bash
chmod +x setup.sh && ./setup.sh
```

Или вручную:

```bash
docker compose build
docker compose up -d
docker compose logs -f reminder-bot
```

## ⚙️ Стек

| Компонент | Технология |
|---|---|
| Язык | Python 3.12 |
| Telegram API | python-telegram-bot 21.6 |
| Планировщик | APScheduler 3.10 |
| Распознавание речи | OpenAI Whisper (tiny, локально) |
| База данных | SQLite |
| Деплой | Docker + Docker Compose |

## 📌 Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и примеры |
| `/list` | Список активных напоминаний |
| `/cancel <id>` | Отменить разовое напоминание |
| `/cancel r<id>` | Отменить повторяющееся |

## 🔒 Безопасность

Файл `.env` с токеном **никогда не попадает в git** — он добавлен в `.gitignore`.  
Не публикуй токен в открытом доступе.
